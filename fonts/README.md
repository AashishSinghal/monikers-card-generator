# Fonts

The official Monikers typeface is **Gotham Rounded** (© Hoefler & Co) — a
**commercial font that is NOT included** in this repo for licensing reasons.

To build with the authentic look, place your own licensed copies here:

| File | Used for |
|------|----------|
| `gothamrnd_medium.otf` | card names |
| `gothamrnd_book.otf`   | clue / description text |
| `gothamrnd_bold.otf`   | point numbers |

Without them, `generate.py` still runs and falls back to Futura / Avenir /
system sans (defined in the CSS font stacks).
